STEP 12 : FILTERING LIVE DOMAINS
================================================================================

Workflow:

    Collect Subdomains
            |
            v
    Merge & Remove Duplicates
            |
            v
    Run HTTPX
            |
            v
    Identify Active Domains

Example:
    subfinder -d target.com -o subf.txt
    assetfinder -subs-only target.com > asset.txt
    httpx -l subdomains.txt -o active.txt

STEP 18 : MANUAL TESTING (OWASP TOP 10 - 2021)
================================================================================

[A01] Broken Access Control
    - IDOR
    - Path Traversal
    - Privilege Escalation

[A02] Cryptographic Failures
    - Weak Ciphers
    - Cleartext Data Exposure
    - Poor Randomness

[A03] Injection
    - SQLi
    - XSS
    - Command Injection
    - LDAP Injection
    - SSTI
    - NoSQL Injection

[A04] Insecure Design
    - Hardcoded Credentials
    - Session Fixation
    - Weak Error Handling

[A05] Security Misconfiguration
    - Default Credentials
    - Insecure Permissions
    - Directory Listing
    - Misconfigured CORS

[A06] Vulnerable Components
    - Outdated Libraries
    - Unpatched Software

[A07] Authentication Failures
    - Brute Force
    - Credential Stuffing
    - Session Hijacking
    - Weak Password Policy

[A08] Software & Data Integrity Failures
    - SSRF Variants
    - Update Tampering
    - Redirect Issues

[A09] Logging & Monitoring Failures
    - Missing Logs
    - Weak Monitoring

[A10] SSRF
    - Authenticated SSRF
    - Unauthenticated SSRF
